# Isle of Larkfall

A browser-playable, story-driven fantasy JRPG prototype inspired by the supplied concept art.

## Play locally

Open `index.html` in a modern browser. The game uses plain HTML, CSS, and JavaScript; no build tools or dependencies are required. Progress is saved in your browser's local storage.

## Controls

- Move: WASD or arrow keys (or the on-screen direction pad)
- Interact: E or the Talk / Interact button
- Explore: use the Explore button to discover encounters
- Combat: Attack, Skill, Potion, Defend, or Run

## Hosting

The project is designed for GitHub Pages. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save. Once GitHub Pages finishes deploying, its URL will appear on that settings page.

## Prototype content

Explore Larkfall Town, Coastal Path, Mistwood Forest, Sunken Ruins, Ashen Cliffs, and the Old Lighthouse. The prototype includes dialogue, a quest journal, exploration encounters, turn-based combat, XP and leveling, inventory, save/continue, the Seal Keeper, and the Angel Feather story path. This is an early playable prototype; additional campaign content can be built on top of it.
